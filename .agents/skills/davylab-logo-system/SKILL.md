# DAVYLAB Logo System
Trigger: "生成logo", "设计标志", "logo design", "brand identity", "DesignOS Logo Studio".
## Workflow
1. Interpret a one-sentence brief; infer defaults but label assumptions. Never invent trademark clearance.
2. Offer quick mode (single sentence) and advanced mode (optional fields): brand name, slogan, industry, audience, brand attributes, logo type (wordmark, lettermark, pictorial, abstract, mascot, emblem, combination), style (minimal, geometric, editorial, expressive, heritage), geometry, typography, color palette, monochrome, negative space, icon/wordmark proportion, applications (app/web/print/signage), aspect ratio, accessibility, references and exclusions.
3. Create 3 differentiated original concepts, each with rationale, symbol construction, typography, palette and monochrome variant. Do not copy logos from logosystem.co or other references.
4. Select a concept, refine alignment, kerning, optical balance, safe zone and min size; verify on light/dark backgrounds, 24/32/64px icons and one-color.
5. Deliver editable SVG plus transparent PNG exports, icon-only, horizontal/stacked variants, palette HEX, typography licensing notes, mini brand guide, brief JSON and QA report. Distinguish previews from final vectors.
6. Mandatory release gates: no external SVG scripts or remote assets; no unlicensed fonts; human review of originality and trademark conflicts; SVG parser/structural QA; no unsupported claims of registration.
## Scoring (100)
Brand fit 20, originality 20, legibility 15, geometry 15, versatility 15, typography/color 10, production readiness 5. >=90 AND all mandatory gates to mark production ready.
