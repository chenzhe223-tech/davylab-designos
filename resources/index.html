让 Agent 自己找到合适的 Skill

将调度中心接入你的 Agent：先按任务匹配，再读取源文件、校验条件，最后应用。匹配结果是推荐，不是自动授权。

Agent API · Discovery

供已连接的 Agent / 服务端检索；以下接口只返回资源元数据，不返回私有 Skill 正文。

GET /api/skills GET /api/skills?q=供应商报价 GET /api/skills/{id} POST /api/skills/match

最简调用方式

Agent 根据任务传入 intent 和自身标识。返回结果会带适用说明、来源路径、SHA 指纹与使用约束。

POST /api/skills/match { "intent": "供应商报价对比", "agent": "WorkBuddy", "limit": 5 }
