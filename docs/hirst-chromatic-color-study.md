## 使用说明

1. 设计台 > 设计方向 > **Hirst Chromatic**。
2. 视觉语言 > **艺术色系** > 四种子风格任意切换；强调色、画布底色和文字色与所选子风格同步。
3. 可继续使用原有设备切换、保存快照、复制/恢复设计、导出 JSON、CSS Tokens、Agent 实施指令。导出记录包含色板与原始来源。
4. 原创预览由本仓 `studio/hirst-chromatic.js` 和 `studio/hirst-chromatic.css` 绘制，不在网页资源包中复制原作。

## 设计与验收边界

- 白色 / 近白色中性画布为主，不使用米色 / 米黄色作为默认基底。
- 70% 中性色 + 20% 有序多色 + 10% 强调色；单张业务卡片最多三种亮色。
- 原作是灵感来源，不是用于商业产品的免费贴图素材；使用正式作品图片需独立检查许可与授权。
- 控件状态需要文本 / 形状双重表达，正文对比度至少 4.5:1；谨慎使用柔粉、亮黄充当正文色。
- 旋转预览支持 `prefers-reduced-motion` 与 DesignOS 减少动效设置，不让复杂动效进入密集工作表。
- 375 / 390 / 430px 视口回归验收；设计预览不代表目标项目已经实现或部署。
- 初始状态为 `draft` / `reviewed`，直到有真实浏览器/生产验收证据才晋级。
