# Web Design Studio · P0

Status: development branch; not production deployed.

## Evidence from current repository
- Existing root is DesignOS 3.0, /classic/ remains preserved.
- Existing local projects and illustrative HTML/CSS previews are not real generated apps.
- Logo Studio is a separate /logo-studio/ route; preserve it.
- Upstream oh-my-design is a DESIGN.md archive + agent skills, **not** a standalone inference service or website generator. Its README explicitly requires a coding agent to generate React.

## Architecture
1. Isolated /web-design-studio/ route; preserve all existing routes and data.
2. Brief -> reference DESIGN.md (provenance + licensing notice) -> AI code generation adapter (real provider required) -> sandboxed runnable preview -> token/property edits -> QA -> export.
3. Reuse WorldToon project lifecycle concept, not its comic-specific renderer.
4. Do not claim a model has run if only a static preview is available.

## Stage gates
P0: interactive editor shell + viewport preview; desktop/mobile screenshot and layout review.
P1: actual oh-my-design reference retrieval, DESIGN.md parsing, provenance, three generated code variants via a configured model; no templates labeled AI.
P2: isolated HTML/React preview with safe sandbox, edits and persistence.
P3: browser visual QA, responsive QA, exports and deploy.
